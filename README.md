# ⚡ VORTEX — Developer Portfolio

A modern, responsive personal portfolio website showcasing my development skills, projects, and experience. Built with a futuristic dark interface, vibrant gradients, and interactive UI elements.

## 🌐 Live Demo

Coming soon — deployment with GitHub Pages.

## ✨ Features

- **Modern Hero Section** — Bold typography, gradient highlights, and introduction.
- **About Me** — Background, interests, and development journey.
- **Skills & Technologies** — Overview of my technical toolkit.
- **Featured Projects** — Showcases projects with links to live demos and source code.
- **Experience Section** — Highlights web development internship experience.
- **Contact Form** — Validates input and prepares an email draft.
- **Responsive Layout** — Designed for desktop, tablet, and mobile screens.
- **Interactive Navigation** — Smooth navigation between portfolio sections.
- **Visual Effects** — Dark theme, gradient accents, and animated UI elements.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages (for deployment)
